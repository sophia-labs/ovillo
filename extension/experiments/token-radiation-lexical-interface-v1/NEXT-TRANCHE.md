# Lexical Interface — next CPU tranche

## N1. Learn the articulatory body

Replace the declared surface renderer with a second persistent body receiving
predictive radiation, operator events, lexical mode/register gestures, and a
finite articulation reservoir.

Compare declared lookup articulation, a learned stateless surface head, a
learned persistent articulatory body, and a strong autoregressive byte decoder.
Keep exact surface reconstruction and carrier/source work separately receipted.

## N2. Train the event process by likelihood

Replace boundary BCE with a latent marked-event objective assigning probability
to every lossless segmentation and operator mark compatible with the byte
surface. Retain supervised boundaries only as an analysis oracle.

## N3. Joint lexical-predictive coupling

Use soft operator posteriors from the lexical body to form mixtures of predictive
source gestures. Compare teacher-forced gestures, detached posteriors, fully
differentiable coupling, and randomized/surface-only controls.

## N4. Active articulation

Add reservoir-paid carrier radiation only after the passive loop is stable.
Book predictive-body loading, articulation reservoir work, carrier emission,
passive loss, and surface radiation separately.

## N5. Operator discovery

Hide operator labels after N1–N3 pass. Ask whether interchange and
counterfactual interventions recover a stable latent operator partition across
surface rerenderings.

## N6. Natural bytes

Natural text remains behind the previous gates. Use bytes as the exact substrate,
BPE as a surface codec/control, and a latent operator layer whose first claim is
parameter sharing or event-rate reduction rather than token replacement.
