# Extension lexical interface program

## Thesis

A token is not merely an output category. It is a boundary event connecting
four distinct systems:

1. an exact surface codec;
2. a lexical recognizer and event clock;
3. a surface-neutral predictive body;
4. an articulatory and feedback compiler.

Token Radiation v0 isolated detector vocabularies over one fixed byte-driven
trajectory. That experiment was necessary, but it prevented vocabulary from
changing computation, body time, source work, or autoregressive feedback.

This tranche restores the bidirectional loop:

```text
surface gesture
  -> lexical body
  -> emitted operator event
  -> predictive source aperture
  -> predictive body
  -> predictive radiation
  -> articulation
  -> surface event
  -> lexical body
```

## Why two bodies

A byte-driven predictive body can memorize and predict surface streams, but its
state transition for a span generally depends on the particular spelling and on
how many material steps the spelling consumed. A post-hoc operator macro then
has to undo that entanglement.

The two-body architecture makes the separation structural:

- the lexical body owns surface ambiguity, event timing, script, and spelling;
- the predictive body owns future-relevant operator state;
- the coupling variable is a named latent operator event;
- a declared source gesture is the only way the event changes predictive state.

## Controlled semantics

The latent state is a small dihedral state plus one lexical mode. Rotation and
reflection are noncommutative. The lexical mode changes the interpretation of
the homograph `ba`.

This permits two causal interventions that a flat token model obscures:

- change the surface while preserving the operator;
- change the operator interpretation while preserving the surface.

## Radiation through time

The instantaneous emission is not required to contain an entire lexical event.
The event detector receives a fixed short trace:

```text
Psi_i = [psi_(i-k+1), ..., psi_i].
```

A temporally shuffled trace is the primary negative control. If shuffling
preserves the result, the detector is using feature marginals rather than
ordered body radiation.

## Feedback constitution

Teacher forcing and free generation must not use different hidden-state update
paths. Both invoke one declared operator source gesture. Direct assignment of a
token embedding or target state is prohibited.
