# Lexical Interface v1 — experiment specification

## Primary question

Can a surface-neutral predictive body participate in a bidirectional lexical
loop when all state changes occur through declared source gestures and all
outputs are measured through radiation?

## World requirements

The controlled world contains:

- noncommuting operators;
- multiple surface realizations per operator;
- a context-dependent homograph;
- variable-length surface events;
- a predictive law depending on persistent latent state;
- surface substrings that do not uniquely identify operator ontology.

## Conditions

### C0 — one-body macro diagnostic

Freeze a byte-driven lexical body. Fit one source macro per latent operator and
one source macro per exact surface form. Both use one lawful source step and are
compared with exact byte replay from held-out live states.

### C1 — lexical radiation body

The body receives bytes only through source gestures. All primary heads see
radiation only.

### C2 — radiation event interface

Fit surface-only, radiation-only, and combined trace detectors for boundary and
latent operator. Counterfactual surface rerenderings are held out. Temporal
radiation shuffle is the primary negative control.

### C3 — surface-neutral predictive body

The body source alphabet contains four latent operator gestures and sixteen
initial predictive-state gestures. It never receives byte IDs.

### C4 — closed surface feedback

At every event:

1. predictive radiation selects an operator;
2. a declared articulator produces a legal surface realization;
3. the lexical body processes the bytes;
4. the event interface recovers an operator;
5. the recovered mark returns through the predictive source gesture.

## Primary endpoints

```text
radiation operator accuracy
radiation homograph accuracy
combined boundary AUC
shuffled-radiation boundary AUC
teacher/feedback state identity
latent closed-loop exact-sequence rate
surface round-trip operator accuracy
closed-loop exact semantic sequence rate
closed-loop exact boundary sequence rate
```

## Support gates

Bidirectional construction requires radiation operator accuracy at least 0.95,
latent feedback exact-sequence rate at least 0.99, surface round-trip operator
accuracy at least 0.85, and exact teacher/feedback path identity.

GPU scale additionally requires exact semantic and boundary sequence rates of at
least 0.90, a learned articulator, an unsupervised or likelihood-trained event
clock, and structural replication.

## Prohibited claims

This tranche may not claim tokenizer independence on natural language, learned
latent operator discovery, learned articulation, unsupervised segmentation,
superiority to BPE, natural-language generation, or GPU readiness.
