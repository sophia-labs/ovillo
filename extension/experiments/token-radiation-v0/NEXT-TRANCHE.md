# Token Radiation — next tranche

## T1. Exact paired loading experiment

Train passive and non-loading continuations from the same initial body,
minibatches, probes, and optimizer state. Cross radiation fractions:

```text
0, 0.01, 0.04, 0.16, 0.50
```

Measure state retention, long-horizon BPB, adaptation after emission, and
radiation per predictive nat.

## T2. Predictive operator vocabulary

Replace substring-endpoint scoring with an operator study.

For candidate surface span `s` and sampled body state `X`, record the byte
micro-rollout:

```text
Phi_s(X).
```

Cluster spans by:

```text
state transition distance
future-test KL
radiation trace distance
work difference
```

Select an epsilon-cover of frequently visited operators. Compare against BPE,
Unigram, and oracle motifs at matched vocabulary description length.

## T3. Macro gesture compiler

For promoted units, fit a shorter lawful operator program `G_s` and compare it to
byte replay on held-out body states.

Required receipts:

```text
state distortion
predictive distortion
radiation distortion
work distortion
microstep reduction
```

No direct hidden-state assignment is allowed as a promoted macro.

## T4. Adaptive event clock

Add a blank/no-event channel or a marked hazard model. Compare boundaries from:

- fixed bytes;
- BPE;
- Unigram;
- entropy change;
- predictive-state innovation;
- learned hazard;
- synthetic oracle motifs.

The event clock must report information carried by timing and remain lossless at
the byte surface.

## T5. Byte-level natural sequence pilot

Start at roughly 1M and 3M parameters with raw bytes. Use a broader corpus plus
Moby Dick as a continuity/interpretability slice.

Baselines:

- byte Transformer;
- selective state-space model;
- dynamic byte patches;
- direct non-loading body readout;
- passive Token Radiation;
- fixed local reservoir.

Match bytes, parameters, training FLOPs, inference FLOPs, recurrent state, and
event rate separately.

## T6. Tokenizer-equivalence gate

Drive one frozen body by exact bytes and observe it with byte, BPE, Unigram,
morphological, and predictive detector banks. Then add input macros and require
body-state and future-distribution agreement at aligned byte boundaries.

This is the first gate that can support the phrase **pre-token predictive body**.

## T7. Active articulation

Only after passive loading is understood, add reservoir-paid radiation. Keep
carrier work, predictive modulation, and body loading separately receipted.

A coherent carrier must not obtain free interference energy. The first safe
implementation should use orthogonal or quadrature carrier channels before
attempting coherent superposition.
