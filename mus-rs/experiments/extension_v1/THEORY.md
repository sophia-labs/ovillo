# Neurons Have Extension: theory of the Clifford string medium

## 0. Status and claim discipline

This document gives the mathematical core of a provisional model family. The exact algebraic statements are elementary and executable. The proposed interpretation as a neural architecture, the local string realization, and the language-modeling consequences are hypotheses.

The construction is **not** novel merely because it uses:

- controlled differential equations;
- finite-dimensional path development;
- Clifford/geometric algebra;
- orthogonal recurrent dynamics;
- extended or compartmental neuron models;
- physical neural networks.

The plausible contribution is their specific synthesis: a trainable sequence medium whose tokens are control gestures, whose persistent state is a multivector field carried by one-dimensional bodies in a learned geometry, whose local operators compile to sparse energy-preserving contacts, and whose changing morphology is subjected to an explicit work/state-transport law.

## 1. Ontological move

A conventional artificial neuron is a point: at one computational instant it carries a scalar or vector, applies an algebraic map, and is overwritten. A conventional layer index stands in for travel through a system.

An extended neuron is instead a one-dimensional material body

```text
gamma_i : [0, 1] -> M,
```

embedded in an ambient latent manifold `M`, initially `R^4`. It carries a distributed state `z_i(s,t)`. Signals propagate along material coordinate `s`; localized contacts couple portions of different bodies; external inputs are paths through the ambient space or through the medium's control space.

The slogan is:

> Layering is a surrogate for travel. Extension replaces the surrogate with travel.

Numerical implementation still uses arrays, sparse matrices, and automatic differentiation. The distinction is that those matrices are constrained lowerings of a declared geometry and material law rather than the model's primitive ontology.

## 2. Gesture-driven sequence computation

Let a sequence element be represented by a path

```text
g : [0, T] -> R^d.
```

A path may be open, or it may be a closed control gesture with `g(0)=g(T)`. The model's state evolves under a controlled equation

```text
dZ_t = F(Z_t) dt + sum_j G_j(Z_t) dg_t^j.
```

Sequence order is intrinsic because the flows generated by the `G_j` need not commute. For a linear development,

```text
dU_t = U_t sum_j D_j dg_t^j,    U_0 = I.
```

The endpoint is the path-ordered exponential

```text
U[g] = P exp integral_g D_j dg^j.
```

For concatenated paths,

```text
U[g * h] = U[g] U[h].
```

For a closed rectangle with increments `a e_i`, `b e_j`, `-a e_i`, `-b e_j`, the Baker--Campbell--Hausdorff expansion gives

```text
U[rectangle] = I + ab [D_i, D_j] + O((|a|+|b|)^3).
```

Thus the visible control endpoint may close while the internal state does not. This is the exact mathematical form of “expression as gesture over latent space.”

## 3. Why Clifford algebra appears

The full path signature takes values in the tensor algebra and records ordered iterated integrals of every degree. It is universal but grows rapidly. A finite-dimensional path development chooses a representation of the tensor algebra into a matrix algebra. This idea already has a direct machine-learning precedent in Path Development Networks.

Extension-v1 chooses a particularly structured quotient: the Clifford algebra associated with the negative-definite metric on `R^d`.

Let `V = R^d` with orthonormal basis `e_1, ..., e_d`. Define generators by

```text
D_i D_j + D_j D_i = -2 delta_ij I.
```

The state representation used here is the exterior algebra

```text
Lambda* V = direct_sum_{k=0}^d Lambda^k V,
```

with dimension `2^d`. Right Clifford multiplication by a vector is represented by wedge minus contraction:

```text
c(v) = epsilon(v) - iota(v).
```

This sign convention gives

```text
c(v)^2 = -||v||^2 I.
```

For unit vectors, `c(v)` is skew-orthogonal. Its exponential is a norm-preserving rotation.

### Proposition 1 — energy preservation

For each basis generator `D_i`,

```text
D_i^T = -D_i,
D_i^T D_i = I,
D_i^2 = -I.
```

Therefore

```text
exp(theta D_i)^T exp(theta D_i) = I.
```

Any piecewise-linear Clifford development built from these exponentials preserves Euclidean state energy exactly in exact arithmetic.

### Proposition 2 — orientation as a sequence observable

Starting from scalar vacuum `1 in Lambda^0 V`, let `v_1, ..., v_d in V`. The grade-`d` part of their Clifford product equals their exterior product:

```text
pi_d(v_1 ... v_d) = v_1 wedge ... wedge v_d.
```

Relative to an oriented orthonormal basis,

```text
pi_d(v_1 ... v_d) = det([v_1; ...; v_d]) e_1...e_d.
```

For a permutation of the basis vectors, the pseudoscalar coefficient is exactly the permutation sign.

This is not a learned coincidence. It is the alternating structure of the exterior algebra.

### Proposition 3 — the medium is a quotient, not a full signature

The tensor algebra maps to the Clifford algebra by imposing the relations

```text
e_i tensor e_j + e_j tensor e_i = -2 delta_ij.
```

Consequently, many different tensor-signature components collapse to the same Clifford element. A single fixed Clifford representation is not a characteristic representation of arbitrary paths. It is a finite, stable, geometrically interpretable projection emphasizing orientation, antisymmetric area, and higher-grade volume.

A scalable model should use multiple fibers, signatures, metrics, projections, or active nonlinear couplings rather than pretend one 16-dimensional state faithfully remembers every linguistic distinction.

## 4. Why four dimensions are interesting

For `d=4`, the exterior grades have dimensions

```text
1, 4, 6, 4, 1.
```

This provides a compact hierarchy:

- grade 0: scalar baseline/intensity;
- grade 1: directed components;
- grade 2: oriented pairwise area/order;
- grade 3: oriented triple interaction;
- grade 4: oriented four-volume/global order.

The model therefore turns a gesture history into a multiscale geometric object rather than a single endpoint vector.

Four is not asserted to be metaphysically privileged. It has three practical attractions:

1. it is the smallest dimension with a nontrivial pseudoscalar over four independent token directions;
2. the complete algebra has only 16 real modes;
3. the five grade groups map naturally to five one-dimensional strings.

The geometric contact experiments show a threshold: at finite contact width, four ambient dimensions realized the intended sparse algebra much more cleanly than two or three, while eight gave little improvement. That is empirical evidence for sufficiency in this construction, not a general theorem of neural computation.

## 5. Sparse local realization

A dense `16 x 16` generator is only a reference representation. Each basis generator `D_j` pairs every blade not containing `j` with the corresponding blade containing `j`:

```text
S <-> S union {j}.
```

There are `2^(d-1)` such disjoint pairs. For `d=4`, each generator is eight signed quarter-turns. Since the planes are disjoint, their order within a generator does not matter.

This yields a physical lowering:

1. Put the 16 blade modes at material sites.
2. Group them into five one-dimensional bodies by grade.
3. For a token/control direction `j`, activate eight local contacts.
4. Each contact performs an energy-preserving signed plane rotation.

The exact sparse program is a natural target for the existing `mus-gesture` compiler and `mus-watsn` executor in `instrument`.

## 6. Geometry-derived contacts

Let material site `a` have ambient coordinate `x_a in R^m`. A soft local mode centered on `a` is

```text
phi_a(x_b) proportional to exp(-||x_b-x_a||^2 / (2 sigma^2)).
```

For a desired pair `(a,b)`, Extension-v1 orthonormalizes `phi_a, phi_b` and performs an exact two-plane rotation. Every individual event therefore remains norm preserving even when its support leaks to unintended sites.

Finite width produces a different problem: the resulting global generator no longer exactly satisfies the Clifford anticommutation relations. The model preserves energy for each basis token program, but an arbitrary linear combination of approximate generators need not be skew-orthogonal. This explains the observed energy drift in random continuous-vector tests at broad contact width.

There are at least four principled remedies:

1. compile arbitrary vector gestures as ordered products of exact local events rather than linear combinations of approximate global generators;
2. reproject approximate generator combinations into the skew Lie algebra before exponentiating;
3. optimize morphology and contact profiles jointly under algebra residuals;
4. use the WATSN metric/polar machinery to separate energy-preserving transport from deformation/work.

## 7. Morphology as a learned computational parameter

The initial inverse-design experiment fixes the operator pairing schedule and optimizes only the shape of the five strings. Let `X(theta)` denote all material coordinates and `D_j(X)` the soft geometric generator. The objective is

```text
L(theta) = sum_j ||D_j(X(theta)) - D_j*||_F^2
           + lambda_curv curvature(X)
           + lambda_iso isotropy(X).
```

The target `D_j*` is the exact Clifford program.

This is deliberately conservative. It asks whether geometry can realize a known computation before asking an optimizer to discover topology, algebra, and task simultaneously. The active-cable negative result suggests this staging is necessary.

A later bilevel problem is:

```text
outer: choose morphology, contact topology, and material families;
inner: train gesture programs and readout on sequence objectives;
constraints: passivity/work, locality, complexity, and remeshing consistency.
```

## 8. Learned closed token loops

A token need not be an open move along a basis vector. In the trainable probe, token `x` owns increments

```text
delta_{x,1}, ..., delta_{x,K}
```

with exact closure

```text
sum_k delta_{x,k} = 0.
```

Its operator is

```text
U_x = product_k exp(sum_j delta_{x,k}^j D_j).
```

Because the generators do not commute, `U_x` is generally nonidentity. A sequence applies the operators recurrently.

The commuting control replaces every `D_j` by the same generator `D`. Then

```text
U_x = exp(D sum_k sum_j delta_{x,k}^j) = I
```

for every closed token. All sequence states collapse. This exact control isolates the contribution of noncommutation.

The learned parity result is stronger than the original open-basis demonstration, but remains a finite complete-task fit. The next scientific question is whether closed gestural programs learn reusable operations that extrapolate in length, composition, and task context.

## 9. From an orthogonal memory to an active neural medium

The exact Clifford development is linear and norm preserving. By itself it is a structured recurrent feature map, not a general language model. A useful medium needs controlled nonlinearity, selective forgetting, source injection, and interactions among multiple fibers.

A proposed state for string `i` is

```text
z_i(s,t) = (q_i, p_i, r_i, m_i),
```

where:

- `q,p` are traveling-wave or Hamiltonian coordinates;
- `r` is an excitable recovery variable;
- `m` is slower contextual/material state.

One candidate law is

```text
partial_t z = (J-R) delta H/delta z
              + N(z; theta_material)
              + B(g(t), gamma(s)) a(t),
```

where `J` is skew, `R` is positive semidefinite, and `N` is a shared local active constitutive law.

The exact Clifford program can supervise or initialize this medium:

1. **operator distillation:** match local Jacobians or finite-step operators to Clifford targets;
2. **trajectory distillation:** match state paths produced by exact closed gestures;
3. **morphology curriculum:** first fit exact local contacts, then unlock active material parameters;
4. **task curriculum:** first preserve algebraic probes, then add algorithmic and language losses;
5. **residual architecture:** keep an exact passive Clifford backbone and let the active law add bounded residual dynamics.

This is the most immediate response to the failed direct active-cable run.

## 10. Work accounting and changing morphology

Once geometry changes during inference, array coordinates cannot simply be reinterpreted. A live field must be transported between old and new state spaces.

Let old and new energy metrics be `M` and `M'`, and let `T` be a proposed state map. In normalized coordinates,

```text
A = M'^(1/2) T M^(-1/2).
```

Take the polar decomposition

```text
A = U H.
```

`U` is energy preserving; `H` carries deformation and control work. This is exactly the work--holonomy decomposition already developed in Ariadne. Extension should reuse it rather than invent an unconstrained geometry update.

The full neural receipt should distinguish:

- input/source work;
- internal active work;
- explicit damping;
- radiation/readout extraction;
- morphology/control work;
- numerical residual.

“Energy preserving” is not synonymous with “good” or “biological.” It is a legible baseline that prevents hidden numerical gain from being mistaken for computation.

## 11. Relationship to attention

A meaningful limiting comparison can be made without claiming identity.

Suppose extended bodies collapse to point states, propagation speed tends to infinity, contacts become globally content addressed, and internal dynamics equilibrate immediately:

```text
epsilon dz/dt = -z + softmax(QK^T)V.
```

As `epsilon -> 0`, the state becomes the algebraic attention update. In this sense attention is a point-like, instantaneous interaction regime. Extension retains finite travel, persistent internal state, local geometry, and path order.

The proposed architecture need not eliminate attention dogmatically. A learned contact gate may reproduce attention when global instantaneous routing is useful. The scientific question is whether the extended regime contributes capabilities or scaling behavior unavailable to the collapsed one.

## 12. Formal obligations

A serious paper should separate exact theorems, numerical identities, and empirical claims.

### Exact/reference-level obligations

1. Clifford relations for the reference generators.
2. Sparse Givens decomposition.
3. determinant/top-grade identity.
4. norm preservation of segment exponentials.
5. multiplicativity under path concatenation.
6. inversion under reversed negative path.
7. time-reparameterization invariance for collinear segment refinement.
8. small-loop commutator expansion.

### Compiler obligations

1. every local event acts only on declared contacts;
2. lowering preserves signed order;
3. metric and basis conventions are explicit;
4. receipts distinguish proof from sampled verification;
5. morphology updates use explicit state transport;
6. no dense matrix factorization occurs in the real-time callback;
7. remeshing preserves continuum semantics within tolerance.

### Empirical obligations

1. controlled same-endpoint path tasks;
2. generic finite-dimensional development baselines;
3. point-collapsed and commuting controls;
4. algorithmic length extrapolation;
5. active-medium ablations;
6. small language modelling;
7. compute and memory scaling;
8. robustness to discretization, geometry perturbation, and timing warp.

## 13. Complexity

The exact exterior representation costs `2^d` state coordinates and `2^(d-1)` local plane rotations per basis generator. At `d=4`, these are 16 and 8. Multiple fibers scale linearly.

The exponential dependence prohibits treating `d` as ordinary hidden width. The intended interpretation is that ambient geometric dimension remains small while capacity grows through:

- many local fibers;
- many extended bodies;
- heterogeneous metrics/material laws;
- sparse inter-fiber contacts;
- active local state;
- hierarchical or tensor-network factorizations;
- potentially minimal spinor modules of dimension approximately `2^(d/2)`.

A language-scale model should not instantiate `Cl(0,4096)`.

## 14. Nearest prior and remaining novelty question

Path Development Networks already define trainable finite-dimensional Lie-group developments of sequences and demonstrate their use in time-series learning. Signature and Neural CDE work already treats streams as paths. Clifford neural networks already process multivectors and learn geometric equivariances. Physical neural networks and dendritic models already use material or compartmental dynamics.

The open novelty question is narrower:

> Does a locally realizable Clifford path development, carried by learned extended bodies and coupled to a work-accounted active medium, provide a useful sequence-model inductive bias?

The current code establishes a coherent object worth testing. It does not yet answer that question.
