Ovillo audition

Every World the portable module builds. Nothing here synthesizes a note: an event or a control touches a World, the World does the sounding, and its ledger is its receipt. Pan, gain and the limiter below each World are the listener's mix, outside the World.

Start audio, then choose a World on the left and build it. Several can run at once: each is its own AudioNode, all in one wasm module.
